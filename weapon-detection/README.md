# Weapon Detection in Forensic Images using a Deep Neural Network

**Digital Image Processing — Case Study**
*YOLOv5s · Handgun & Knife Detection · Forensic Image Analysis*

---

## Overview

This project trains and evaluates a **YOLOv5s** object detector to locate and classify
**handguns** and **knives** in forensic images, providing both bounding-box outputs
and an image-level verdict ("contains handgun / knife / no weapon detected").

A classical-DIP preprocessing ablation (CLAHE) and a model-size comparison
(yolov5n / yolov5s / yolov5m) support the architectural design choices discussed
in the project report.

## Setup

### 1 · Prerequisites

- Python 3.12 (tested; 3.10+ should work)
- Windows PowerShell (Linux/macOS: replace `.venv\Scripts\Activate.ps1` with `source .venv/bin/activate`)
- GPU recommended (CUDA). CPU-only will work for inference and smoke tests.

### 2 · Create and activate virtual environment

```powershell
cd weapon-detection
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 3 · Install dependencies

```powershell
pip install -r requirements.txt
```

For GPU training (CUDA 11.8):
```powershell
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
```

## Dataset Download

The dataset is "Weapon Detection Dataset for YOLOv5" by raghavnanjappan on Kaggle
(~4 000 images, 2 classes: handgun, knife, YOLO format labels).

### Option A — Kaggle API (recommended)

1. Create a Kaggle account and go to **Account → API → Create New Token**
2. Save `kaggle.json` to:
   ```
   C:\Users\<YOUR_USERNAME>\.kaggle\kaggle.json
   ```
3. Run:
   ```powershell
   python scripts/download_dataset.py
   ```

### Option B — Manual download

1. Download from: https://www.kaggle.com/datasets/raghavnanjappan/weapon-dataset-for-yolov5
2. Unzip into `weapon-detection\data\raw\`
3. Run `python scripts/download_dataset.py` to validate.

## Classical DIP Preprocessing (CLAHE Ablation)

CLAHE (Contrast Limited Adaptive Histogram Equalisation) is applied on the **L channel
of the LAB colour space** to enhance contrast in forensic images without over-amplifying
noise. Parameters: `clipLimit=2.0`, `tileGridSize=8×8`.

The ablation trains YOLOv5s with and without CLAHE preprocessing and evaluates on:
1. Normal val set
2. Val set degraded with Gaussian noise / blur / low brightness

Results in [`results/clahe_ablation.md`](results/clahe_ablation.md).

## Limitations and Ethics

### Technical Limitations

- **Dataset bias**: The training dataset (~4 000 images) may not represent the full
  diversity of forensic image conditions (lighting, camera angle, occlusion, resolution).
  Performance on real-world forensic images may differ from reported metrics.

- **False positives on look-alike objects**: Objects with similar shapes to weapons
  (electric drills, wrenches, dark-coloured mobile phones, toy guns) can produce
  high-confidence false detections. This is a known limitation of appearance-based
  detectors that lack semantic scene understanding.

- **Small objects**: Knives occupying less than ~5% of image area are frequently missed
  due to limited feature resolution at small scales.

- **Occlusion and truncation**: Partially visible weapons (concealed under clothing,
  cut off at image border) are harder to detect reliably.

- **No GPU, no full training**: Training YOLOv5s for 100 epochs on CPU is impractical.
  Use the provided Colab notebook. Reported metrics reflect actual training results;
  placeholder `[pending]` values must be replaced after a full GPU run.

### Ethical Considerations

- **Decision-support tool only**: This system is intended as a decision-support tool
  for qualified forensic experts. It must **not** be used as an autonomous decision-maker
  in legal, law-enforcement, or security-critical contexts.

- **Human review required**: All detections must be reviewed and validated by a trained
  forensic analyst before any conclusion is drawn.

- **Privacy**: Processing surveillance or forensic images requires compliance with
  applicable data protection laws (e.g., GDPR). Images of individuals should not be
  processed without proper legal authorisation.

- **Potential for misuse**: Weapon detection models could theoretically be used to
  train adversarial examples that evade detection. The model weights should be treated
  as sensitive artefacts.
